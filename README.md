# Email Starter

Modern email starter with React Email and TypeScript. Build responsive, production-ready HTML emails using React components.

## Features

- React Email components for structured, reusable email markup
- TypeScript for type-safe templates
- Tailwind CSS styling — compiled to inline styles at render time (works in Gmail, Outlook, etc.)
- Live preview dev server with hot reload
- Export to standalone HTML

## Requirements

- Node.js 22+ (current LTS)
- pnpm 11+

These versions are enforced via `engines` in `package.json` and `engine-strict=true` in `.npmrc` — `pnpm install` will fail on unsupported runtimes.

### Supply-chain security

This project sets `minimumReleaseAge: 10080` (7 days, in minutes) in [`pnpm-workspace.yaml`](./pnpm-workspace.yaml). pnpm will refuse to install any package version published less than 7 days ago, giving the ecosystem time to detect and unpublish compromised releases.

To bypass the cooldown for a specific urgent fix, add it to `minimumReleaseAgeExclude` in `pnpm-workspace.yaml`:

```yaml
minimumReleaseAgeExclude:
  - some-package@1.2.3
```

## Quick Start

```bash
git clone https://github.com/jeremN/Email-starter.git
cd Email-starter
pnpm install
pnpm dev
```

The dev server starts on http://localhost:3000 and lists every template found in `src/emails/`.

## Scripts

| Script | Description |
| --- | --- |
| `pnpm dev` | Launch the React Email dev server with live preview |
| `pnpm build` | Export all email templates to HTML in `out/` |
| `pnpm preview` | Same as `build`, then log a confirmation message |

## Project Structure

```
src/
  components/
    EmailLayout.tsx    Shared wrapper: Tailwind config, Head, Header, Footer
    Header.tsx         Logo / title header
    Footer.tsx         Company info, social links, unsubscribe link
    Button.tsx         Styled CTA button
    SocialLinks.tsx    Social media icon row
  emails/              Email templates (one .tsx file per template)
static/                Static assets served by the dev server
out/                   HTML output (generated by `pnpm build`)
```

## Adding a New Template

1. Create a new `.tsx` file in `src/emails/`
2. Default-export a component that wraps its content in `<EmailLayout>`:

   ```tsx
   import { Section, Text } from "react-email";
   import { EmailLayout } from "../components/EmailLayout";

   interface MyEmailProps {
     previewText: string;
     name: string;
   }

   export default function MyEmail({ previewText, name }: MyEmailProps) {
     return (
       <EmailLayout previewText={previewText} companyName="Acme Inc.">
         <Section className="px-8 py-6">
           <Text>Hello {name},</Text>
         </Section>
       </EmailLayout>
     );
   }

   MyEmail.PreviewProps = {
     previewText: "A short preview shown in the inbox",
     name: "Jane",
   } satisfies MyEmailProps;
   ```

3. `PreviewProps` is a react-email convention: the dev server uses these values as default props when rendering the preview.

The dev server picks up the new file automatically.
